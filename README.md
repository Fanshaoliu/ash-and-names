# 明天照常营业 · Tomorrow, Open as Usual

一个手机和电脑都能玩的原创 2D 像素探秘游戏。v3 将原《灰烬之名》重做为没有战斗、怪物和装备管理的故事旅程。

**[开始今天的调查](https://fanshaoliu.github.io/ash-and-names/)** · [完整剧本](./剧本.md) · [思想手记](./思想手记.md)

AI 让人们能够自由操纵物质。早餐可以凭空合成，排队仍需本人到场。一位跑腿员接到一份多出来的早餐，地址是“本店不存在的第四位顾客”。这份订单背后，是一扇想请假的门。

## 可以玩到什么

- 8 个日常悬案，16 条调查路线，24 个处置分支，8 件可选闲事。
- 35 张相互连接的地图：群岛大地图 → 城镇与城堡 → 室内 → 阁楼、旧校准室、地下河道。进入门后加载独立地图，退出回到原来的门前。
- 6 种结局，出现条件取决于之前的实际安排；全收集追加洗碗尾声。没有唯一真结局。每案可回溯到调查或处置之前，后续记录随之撤回。
- 主角团使用分方向四帧步行，右向镜像左向；固定脚底、地面阴影、碰撞和前后遮挡。澪、铃采用白衬衫、针织背心与百褶裙的日常制服造型，NPC 有各自头像。
- 新封面、统一的城镇建筑素材，以及本地加载的 Fusion Pixel 中文像素字体。
- 32 组可选思想手记，涵盖此在、在世存在、上手与在手、常人、畏、操心、本真性、向死而在、时间性、座架、无蔽、艺术与栖居等主要脉络。

全部分支剧本约 2 万中文字符、452 条对话，思想手记约 9800 字符。分歧会改变调查地点、后续回应与结局条件，并非每种组合都另写一部互不相同的长篇故事。主线内容固定写作，不调用大模型 API。

## 操作

方向键或 WASD 行走，E / 空格交谈与查看。也可点地面自动走路、点人物靠近交谈、点建筑走到门口。手机支持点选和屏幕方向键、A 键。

每案先与委托人谈话并选择路线，找到两条共同线索及一条路线线索，再回去商量处置。`指一下路`会指出下一处地点，也能带你走向当前地图内的目标。不会跨地图瞬移。

M 地图，J 便签，Y 分歧。阅读札记不影响通关，不设知识测验、本真分数或 AI 觉醒指数。

## 存档

进度自动保存在当前浏览器。跨设备请从“存档”导出 JSON，在另一台设备导入；没有账号或云同步。旧版 v1/v2 的浏览器存档保留不动，因剧情与地图彻底改变，不转换为 v3 进度。

回溯会撤回该节点之后的剧情与线索；已见结局作为阅读收藏保留。保留多条完整进度时请分别导出。

## 本地运行与验证

无需安装依赖，在本目录执行：

```sh
python3 -m http.server 8765
```

打开 `http://127.0.0.1:8765/`。GitHub Pages 从 `main` 根目录发布。字体、剧本和图片均在仓库内，运行不需要 API、密钥或外部 CDN。

Node.js 18 以上可运行：

```sh
npm test
npm run books
```

自动验证使用模拟 DOM 驱动实际游戏逻辑，覆盖地图可达、门的往返、48 个章节内路线与处置组合、剧情推进、暗道谜题、存档校验及回溯。浏览器验证与自动检查的边界见 [验证记录](./验证记录.md)。

## 文件与美术来源

`story.js` 是剧情源；`philosophy.js` 是可选阅读；`world.js` 定义嵌套地图与通行；`art.js` 绘制像素地形、角色、道具与遮挡；`game.js` 处理移动、对话、分歧和保存。

`assets/cover-v3.png`、`walk-v3.png`、`world-v3.png` 为新生成的原创美术，提示词与网格记录随附。运行时将素材统一到逻辑像素尺寸、逐帧对齐脚底；旧 `characters.png` 用于其他 NPC。`fanshao.webp` 沿用之前制作的凡少宠物，作为档案馆中旧吉祥物的可查看彩蛋，未改变已安装的宠物。

字体来自 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)，官方 2026.09.01 发布版，SIL OFL 1.1；授权及上游许可存放于 `assets/fonts/`。

地图组织参考 SFC 时代《勇者斗恶龙》的大地图、城镇、室内层次；角色与字体方向参考细致的像素游戏。没有下载或打包商业游戏 ROM，也没有使用这些作品的原素材。参考了 [DQ6 SFC 公开地图资料](https://pidlio.com/dq/dq6sfc/) 与 [Square Enix 攻略书介绍](https://magazine.jp.square-enix.com/gamebooks/books/10133)，不宣称分析过原游戏内部代码。本作不是这些作品的官方作品。

## 哲学与人工智能

“前魔法”指科学技术高度发展后的生活外观，并非超自然元素体系。剧情基于海德格尔的分析框架，重新追问此在、技术与人工智能之间的关系，不预设 AI 必然拥有或永远不能拥有此在的一切特征。

此在不是灵魂认证，也不简单等同于意识。行为证据、生成机制、第一人称叙述与伦理安排需要分别考察；给予某种照料不构成存在论证明。故事中的制度选择是当代叙事延伸，不冒充海德格尔本人提出的 AI 理论。

32 组主题不能穷尽所有重要概念。各组给出德文术语、原典节号或篇目、容易误读的地方及开放问题；早期与后期思想的差异、翻译与诠释争议保留。来源见 [思想手记](./思想手记.md)。
